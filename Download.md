# Download OPNsense On Mac:
Open the official download page:
Download OPNsense: https://opnsense.org/download/
## Select:
  - Architecture: amd64
  - Image type: dvd
  - Mirror: Germany
Download the ISO file (.iso.bz2).

Open VirtualBox:

## Step 3 – Configure OPNsense:
Recommended virtual machine settings:
| Setting      | Value       |
|--------------|-------------|
| RAM          | 4 GB        |
| CPU          | 2 cores     |
| Hard disk    | 20 GB       |
| Network      | 2 adapters  |
| Installation | ISO         |
